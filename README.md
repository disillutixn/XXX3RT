# Ruslan Binazarov — Personal Links

A simple personal link-in-bio website designed for GitHub Pages.

## Before publishing

1. Open `index.html`.
2. Replace every `YOUR_USERNAME`, `YOUR_EMAIL@example.com`, and `YOUR_USER_ID` with your real information.
3. Put your profile photo in this folder and name it `profile.jpg`.
4. Optionally put your CV PDF in this folder and name it `CV.pdf`.
5. Upload all files to a GitHub repository.
6. Enable GitHub Pages in the repository settings.

No build process or dependencies are required.
